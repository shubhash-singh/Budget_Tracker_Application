A simple and intuitive **Budget Tracking App** built using **Android Studio (Java)** and **Firebase Firestore** to help users manage their expenses efficiently.

## 📱 Features

- 🔐 **Authentication** – Secure login/signup using Firebase Authentication.
- 💵 **Add Transactions** – Users can add their income or expenses with a description and amount.
- 📊 **Real-time Updates** – Transactions and balance are synced in real-time using Firestore.
- 📂 **Category Classification** – Categorizes entries (like Food, Travel, Shopping, etc.) using AI (Gemini API).
- 📈 **Expense Overview** – Displays a total balance, income, and expenses in an intuitive UI.
- 🌙 **Dark Mode Ready** – Clean and modern UI with light/dark mode support (if applicable).
- 🔄 **Automatic Sync** – Data synced across devices using Firebase backend.

## 🔧 Setup Instructions

1. **Clone the repository**

```bash
git clone https://github.com/shubhash-singh/Budget_Tracker_Application.git
```

2. **Open in Android Studio**

- File > Open > Select the project folder.

3. **Add Firebase configuration**

- Add your `google-services.json` file into the `app/` directory.
- Set up your Firestore and Authentication services on Firebase console.

4. **Run the app**

- Connect your device/emulator and run the app via Android Studio.
